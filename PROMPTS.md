# AI Development Prompts

This file documents the AI-assisted development used during the
Car Dealership Inventory Management System project.

The prompts below represent the major areas where AI assistance was used
during development, debugging, testing, deployment, and documentation.

---

## 1. Project Planning

> I have a TDD Kata problem statement for a Car Dealership Inventory System.
> Help me understand the requirements and plan the backend, database,
> authentication, frontend, testing, GitHub, and deployment.

---

## 2. Backend and Database

> Help me build the FastAPI backend for the Car Dealership Inventory System
> using SQLite and SQLAlchemy. Create the required user and vehicle models,
> schemas, database configuration, and REST API structure.

---

## 3. Authentication and Authorization

> Implement user registration and login using FastAPI. Add password
> hashing and JWT-based authentication. Protect vehicle APIs and implement
> administrator-only authorization where required.

---

## 4. Vehicle and Inventory APIs

> Implement the vehicle inventory APIs including adding, viewing, searching,
> updating, deleting, purchasing, and restocking vehicles. Ensure that
> purchases cannot reduce stock below zero and admin-only operations are
> properly protected.

---

## 5. Frontend Development

> Help me create the frontend for the Car Dealership Inventory System using
> HTML, CSS, and JavaScript. Include registration, login, dashboard,
> vehicle display, purchase functionality, and inventory management.

---

## 6. Frontend-Backend Integration

> Connect the frontend to the FastAPI backend. Configure the API URL,
> send JWT tokens with protected requests, handle login responses, and
> display appropriate messages when the backend cannot be reached.

---

## 7. Debugging and CORS

> The deployed frontend is showing "Unable to connect to backend".
> Help me debug the API URL, FastAPI CORS configuration, frontend requests,
> and Render deployment.

---

## 8. Test-Driven Development

> Help me follow the Red-Green-Refactor TDD approach for the backend.
> Create meaningful Pytest tests for authentication, protected APIs,
> vehicle operations, and inventory functionality.

---

## 9. Test Debugging

> My Pytest suite is failing. Help me identify the cause of the failure,
> correct the test or implementation, and verify that the complete test
> suite passes.

---

## 10. Git and GitHub

> Help me review Git status, add the modified backend and frontend files,
> create meaningful commits, push the project to GitHub, and verify that
> the repository is up to date.

---

## 11. Deployment

> Help me deploy the FastAPI backend and frontend to Render. Configure the
> correct build and start commands and connect the deployed frontend to
> the deployed backend API.

---

## 12. Documentation

> Help me prepare professional README.md and PROMPTS.md documentation
> covering the project overview, features, technology stack, API endpoints,
> setup instructions, testing, GitHub repository, deployment, and AI usage.

---

# AI Usage Reflection

ChatGPT was used as an AI-assisted development and learning tool throughout
the project.

AI assistance was used for understanding requirements, planning the project
structure, developing and debugging FastAPI APIs, working with SQLite and
SQLAlchemy, implementing JWT authentication, integrating the frontend with
the backend, writing and debugging tests, managing Git and GitHub,
configuring Render deployment, and preparing project documentation.

AI-generated suggestions were reviewed, adapted, and tested during
development. Errors were investigated locally and the backend test suite
was executed to verify the implementation.

AI was used as a development assistant to improve productivity and
understanding, while the final implementation was reviewed and modified
according to the project requirements.
